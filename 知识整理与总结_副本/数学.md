### 例题1: [Reverse Card](https://codeforces.com/contest/1967/problem/B1)

#### Solutions

Denote $\gcd(a,b)$ as $d$. Assume that $a=pd$ and $b=qd$, then we know that $\gcd(p,q)=1$.

$(b\cdot\gcd(a,b))\mid (a+b)\iff (qd^2)\mid (pd+qd)\iff (qd)\mid (p+q)$.

Assume that $p+q=kqd$, then $p=(kd-1)q$. We know $q=1$ because $\gcd(p,q)=1$.

Enumerate $d$ from $1$ to $m$, we know $p+1=kd\le\lfloor\frac{n}{d}\rfloor+1$, so we add $\left\lfloor\frac{\lfloor\frac{n}{d}\rfloor+1}{d}\right\rfloor$ to answer.

In this method, $p=0,k=1,d=1$ will also be included in the answer, so we should subtract $1$ from the answer.

Time Complexity: $\mathcal O(\sum m)$​.

### 例题2: [Reverse Card(Hard Version)](https://codeforces.com/contest/1967/problem/B2)

#### Solution:

Denote $\gcd(a,b)$ as $d$. Assume that $a=pd$ and $b=qd$, then we know that $\gcd(p,q)=1$.

$(a+b)\mid (b\cdot\gcd(a,b))\iff (pd+qd)\mid (qd^2)\iff (p+q)\mid (qd)$.

We know that $\gcd(p+q,q)=\gcd(p,q)=1$, so $(p+q)\mid d$.

We also know that $p\ge 1,q\ge 1$, so $p < d=\frac{a}{p}\le \frac{n}{p}$ and thus $p^2 < n$. Similarly, we can prove $q^2 < m$.

So the number of $(p,q)$ is $\mathcal O(\sqrt{nm})=\mathcal O(n+m)$. We can enumerate each $(p,q)$ such that $\gcd(p,q)=1$ and calculate the answer. $(p+q)\mid d$ is required, so we add $\left\lfloor\frac{\min\{\lfloor\frac{n}{p}\rfloor,\lfloor\frac{m}{q}\rfloor\}}{p+q}\right\rfloor$.

Time Complexity: $\mathcal O(\sum n + \sum m)$​​.

### 最大公因数GCD

#### 欧几里得算法：

1. $g|a ,g|b\iff g|(a-\left\lfloor\frac{a}{b} \right\rfloor b)\iff g|(a\mod b)$ 
2. $\gcd(a,b)=\gcd(b,a\mod b)$ 这个式子等价于上一个式子
3. $\gcd(a,0)=a$ 
4. 单词求gcd的时间复杂度是对数级别的。对于一组n个数字求他们的gcd的时间复杂度是 $O(n+\log w)$ 本质上是线性的。

#### Stein算法

欧几里得算法的缺陷在于，大整数对大整数对取模比较困难切复杂度高。

```c++
// 仅表示流程，没考虑大整数以及取
int gcd(int x,int y) {
    if (x<y) std::swap(x,y);
    if (y==0) return x;
    if (x%2==0 && y%2==0) return gcd(x/2,y/2)*2;
    else if (x%2==0) return gcd(x/2,y);
    else if (y%2==0) return gcd(x.y/2);
    else return gcd(y,x-y);
}
// 每次减法之后必定会缩小2倍，所以时间复杂度是log级别的
```

#### 扩展欧几里得

作用：求解线性同于方程

线性同余方程写作 $ax\equiv c(\mod b) \iff ax+by=c$​ 

考虑$d=\gcd(a,b)$ 找到先找到一组 $ax+by=d$ 的解

考虑倒叙构造，欧几里得的最后是 $dx + 0y = d$ 此时显然有解 $x=1,y=0$ 

利用数学归纳法，假设当前的解是 $bx' + (a\mod b)y' = d$ 我们希望找到 $ax+by= d$ 的解

显然有 $bx'+(a-\left\lfloor\frac{a}{b} \right\rfloor b)y'=d$ 即 $ ay'+b(x'-\left\lfloor\frac{a}{b} \right\rfloor y')=d$ 

则有 $x=y',y=x'-\left\lfloor\frac{a}{b} \right\rfloor y'$​​​ 得解

> exgcd 求出的 ax+by=c*a**x*+*b**y*=*c* 保证的是 ∣x∣≤∣bc∣,∣y∣≤∣ac∣∣*x*∣≤∣*bc*∣,∣*y*∣≤∣*ac*∣

`````c++
inline int exgcd(int a, int b, int &x, int &y) {
	if (b == 0) {x = 1, y = 0; return a;}
	int d = exgcd(b, a % b, x, y);
	int z = x; x = y, y = z - y * (a / b);
	return d;
}
// 要求解同于方程请最后给xy扩倍。不要改变初始值，除非你确定xy不会炸数据范围,或者能够及时取模
`````

#### 欧拉筛法（线性筛法）

根据唯一分解定理，每个数字都用最小的质因数筛出来，避免了重复筛掉一个数造成的时间浪费。

```c++
int v[N+2];std::vector<int> pri;
void primes(int n) {
    memset(v,0,sizeof v);
    for (int i=2;i<=n;i++) {
        if (!v[i]) {v[i]=i; pri.push_back(i);}
         // 请注意这里没有continue
        for (int j=0;j<pri.size();j++) {
            // 一个数字被他的最小质因数筛掉
            // 要么来自枚举的质因数(pri[j])
            // 要么来自当前的数的最小的质因数（v[i]）
            if (pri[j]>v[i] || pri[j]>n/i) break; // 这么写防止溢出
            v[i * pri[j]] = pri[j];
        }
    }
}
```

## 中国剩余定理

### 朴素中国剩余定理

定义；CRT可以求解如下形式的一元线性同于方程组，其中要求 $n_1,n_2,...,n_k$ 两两互质

过程：

1. 计算所有模数的积n
2. 对于第i个方程，计算$m_i = \frac{n}{n_i}$ , 计算 $m_i^{-1}(\mod n_i)$ , 计算 $c_i=m_im_i^{-1}$ 
3. 方程组在模n意义下的唯一解为 $x=\sum_{i=1}^{k} a_ic_i(\mod n)$​ 

```c++
LL CRT(int k, LL* a, LL* r) {
  LL n = 1, ans = 0;
  for (int i = 1; i <= k; i++) n = n * r[i];
  for (int i = 1; i <= k; i++) {
    LL m = n / r[i], b, y;
    exgcd(m, r[i], b, y);  // b * m mod r[i] = 1
    ans = (ans + a[i] * m * b % n) % n;
  }
  return (ans % n + n) % n;
}
```

## 概率与期望

用期望避免分类讨论（无穷假设失败的情况）

如果成功概率是1/10，那么我期望10次就要成功一次，不用一直假设成功假设失败一直讨论下去

例题：[爬树的甲壳虫](https://www.acwing.com/problem/content/4649/)

```c++
#include <iostream>
#include <cstring>
#include <cmath>
#include <algorithm>
#include <cstdio>

typedef long long ll;
const ll mod = 998244353;

ll q_pow(ll x, ll y) {
    if (y == 0) return 1;
    ll mid = q_pow(x, y / 2);
    if (y % 2)
        return mid * mid % mod * x % mod;
    else
        return mid * mid % mod;
}

ll inv(ll a) {
    return q_pow(a, mod - 2);
}

int main()
{
    ll n, ans = 0;
    std::cin >> n;
    for (int i = 1; i <= n; i++) {
        ll a, b;
        std::cin >> a >> b;
        ans = (ans + 1) % mod;
        ans = ans * b % mod * inv(b - a) % mod;
    }
    std::cout << ans << std::endl;
    return 0;
}
```

### 如何求平方的期望

例题：[Expected Power](https://codeforces.com/contest/2020/problem/E) 

题干大意：有这样一系列随机出现的数字a，每个数字出现的概率是p，然后定义y为所有出现的数字的异或和。现在要求 $E(y^2)$ 的值

数据范围：$a_i\le 1023 ,n\le10^5,p\in[0,1]$ 

思考过程：

这道题目你无法知道x的每种情况出现的概率，因为x的期望也是通过线性组合找出来的。

考虑 $E(x)=b_n*2^n+b_{n-1}*2^{n-1}+...+b_0*2^0$ 其中 $b_n$ 是该位置出现1的概率。

如此求和就可以计算出来 $x$ 的期望。那么现在考虑计算 $E(x^2)$ ，从结果来看，仿照前面，我们容易写出 $E(x^2)=\sum_{i=1}^n\sum_{j=1}^nb_{ij}*2^{i+j}$ ，（这个式子的意思是，最终结果的第i+j位之上的1出现的概率 $b_{ij}$ 乘上贡献。然后线性组合出最终的结果）

但是这个式子没有那么容易计算。如果i和j独立的话，我们可以考虑直接用等式 $b_{ij}=b_i\times b_j$ 得到（因为一定要两个位置都是1才会有最终的贡献）。但是显然这里i和j位置上面的1不是独立的。那么我们相当于要对每一个数字进行计算 $b_{ij}$​ 然后合并到一起。

具体地说，对于每一个数字，枚举ij位置，然后把这个数字上这两位对于答案的贡献统计了就可以了

为什么只要枚举两个的乘法贡献就对了，就可以了，因为求 $x^2$ 换句话说 $y=x^3$ 就要枚举三个了。。。

> 其实还有一个更直接的理解方式，那就是直接把x的表达式写出来，然后展开成为x^2然后再利用期望的线性性质进行计算

例题：[A Game On Tree](https://qoj.ac/contest/1817/problem/9530)

很巧妙的题目
首先根据期望的贡献公式把贡献分成两个部分（自己的贡献和两两相互的贡献）
（平方的期望一般都这么处理，不然就只能按照定义枚举E(x^2)的x进行计算，这显然是无法做到的）
然后第一部分直接可以统计
第二部分其实是一个路径问题，而且是一个与树的结构无关的统计！
想到了什么！
显然可以转化成点分治的思考方式来解决。不过这里由于统计的性质比较简单，所以并不用真的去用点分治重新建树计算，直接简单的换根dp就可以了
由于这里是边的最近公共祖先，所以和点的讨论稍微有些区别
后续转移的过程中还用到了一些简单的线性代数知识作数学优化，不然最坏情况就会变成 O(n^2)

一眼可以看到（图一乐的说）第一个要求比较难满足，那么就先考虑后面的那个“每首歌都只有在其他k首歌播放完成之后才能播放”这很容易，直接乘法原理乱搞即可。然后考虑二项式反演，g[i]表示钦定i个元素一定不会被选中，其他元素随意的方案数。那么其实就是第一个问题的规模变成(n-i)即可。然后后面套路二项式反演即可。

### 二项式反演

> 本质上二项式反演就是一种容斥的特殊情况，可以不用枚举子集，直接通过反演得出结果。

![image-20241022012722194](/Users/chenjiayou/Library/Application Support/typora-user-images/image-20241022012722194.png)

![image-20241022012703308](/Users/chenjiayou/Library/Application Support/typora-user-images/image-20241022012703308.png)

> 通常我们先要维护出至少序列 $g[i]$ 然后再利用形式4进行计算，得到 $f[i]$

> 请一定注意，妥善理解钦定一定是运用二项式反演的关键中的关键

```c++
// 形式4下根据g[i]求f[k]的代码
int ans = 0;
for (int i = k; i <= n; i++) {
    if ((i - k) % 2 == 0) {
        ans += C(i, k) * g[i] % mod;
    } else {
        ans += C(i, k) * g[i] % mod * (mod - 1) % mod;
    }
    ans %= mod;
}
std::cout << ans << std::endl;
```

例题1:[信封问题](https://www.luogu.com.cn/problem/P1595)

这是个错排问题。所以下面的正确就是指正确匹配，错误就是指错误匹配。很明显答案是所有人都错误匹配的方案数。$g[k]表示的是至少有k个人正确排序，显然有g[k]=C_n^k*(n-k)!$ 后略

例题2:[集合计数](https://www.luogu.com.cn/problem/P10596)

题目让求解的是恰好有k个交集的情况。不难想到利用二项式反演进行转化。首先n个元素会有 $2^n$ 次方个集合。那么假设我们钦定k个人为交集，$g[k]表示钦定k个元素为交集其他元素不作限制时的方案数$。请注意这与直接说“至少有k个交集的情况下的方案数量”是不等的。

> 考虑如下的例子：
>
> 有元素集合 S = {1, 2, 3}
>
> 若g[k]表示钦定2个元素其他元素不限制的集合数量那就是6种; {{1, 2}, {2, 3}, {1, 3}, {1, 2, 3}, {2, 3, 1}, {1, 3, 2}}
>
> 若g[k]表示至少2个元素的集合数量那就是4种; {{1, 2}, {2, 3}, {1, 3}, {1, 2, 3}}
>
> 一般认为钦定元素不同则一定不同，所以前者的“全集”被计算了3次。

那么就有了包含这k个钦定元素的集合数量就很好计算了是$2^{n-k}$个集合，对于这k个钦定元素来说，这些集合都包涵。所以随便去取都是合法的方案数。同时再配合从n个数里选出k个这样的组合数，所以就得到如下公示 $g[k]=C_n^j*2^{2^{n-k}}$ 后略

例题3:[分特产](https://www.luogu.com.cn/problem/P5505)

我们参考信封问题的思路，定义$g[k]表示至少有k个钦定的人一个特产也没有分到的方案数$ 显然满足二项式反演的性质与条件，最终的答案就是 $f[0]$ 不妨自己推一推f的含义。难点在于如何计算 $g[k]$ 。不难想到先套一个组合数确定是哪k位人，然后省下的人随意分特产，可以有空余。这里直接给出公示 $g[k]=C_n^k*\prod_{i=1}^mC_{a[i]+(n-k)-1}^{(n-k)-1}$ 这个公式由插板法而来，想来不难理解。需要读者思考的是另一种看起来很对的计算方法为什么是错误的 $sum=\sum_{i=1}^ma[i],tot=\frac{sum!}{\prod_{i-1}^m a[i]!},g[k]=C_n^k*C_{tot+(n-k)-1}^{(n-k)-1}$

例题4:[已经没有什么好害怕的了](https://www.luogu.com.cn/problem/P4859)

这道题目也是难在g[k]的求解。首先我们可以根据n和m直接计算出应该有几个配对是糖大的。假设是k对。

我们希望求解恰好k对糖大的方案数。这比较困难，转化成去求解钦定k对糖大，其他不管的方案数（假设已经求出来了是$dp[n][k]$ ） 那么就很好得到公示 $g[k]=(n-k)!*dp[n][k]$ 。接下来考虑如何求解钦定k对糖大其他不管的方案数。设 $dp[i][j]表示考虑前i个元素，钦定j对糖大的方案数$ $dp[i][j]=dp[i-1][j]+dp[i-1][j-1]*(small[i]-(j-1)),small[i]表示的是小于a[i]元素的b元素数量（这里要a数组从小到大更新）$
