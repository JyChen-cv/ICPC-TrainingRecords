## 区间rank(k)的N种解法

------------

题目背景：给定一个长度为n的序列，每次询问一个区间里面排名第k的值是多少，共有m次询问。

**先考虑一个弱化的题目**：

在一个给定的序列上，每次询问一个区间 $(l,r)$和一个数字k，回答该区间内小于等于k的数有多少个？

数据范围 $n,m \le 10^5 , k \le 10^9$​ 

**解法1: 线段树(归并树)上面二分**

一句话概括就是：思考归并排序的过程和线段树的性质，我们可以在nlogn的时间内预处理出一颗线段树，这个线段树的每个节点都是一个有序的序列。由于线段树的性质我们可以知道，对于每个询问，线段树一定会把区间分成logn份，我们只需在每一段上面跑二分就好了。

时间复杂度：$ O(n\log n \,+\, m\log^2n )$​ 

如果需要修改的话，单次修改的时间复杂度是$O(n)$，整体复杂度会退化到$O(mn)$ 

**解法2: 把这个问题看作一个二维数点问题，适用于离线情况**

利用二维数点的思想，给一维度排序，另一维度用树状数组处理。

首先先去离散化所有的数值方便转换到值域上处理（当然我们完全可以给值域排序来规避掉离散化）

对于所有的区间询问利用前缀和的思想，转化成为挂在某个点上的询问，这样处理完共有 $2m$ 个询问

时间复杂度：$ O(m\log n)$​ 

离线无法修改

**所以区间rank(k) 其实就是在外层套一个二分，二分一下什么值是第k个**

如果一个问题的复杂度达到了 $O(\log^3n)$ 那他的时间是远远不如 $O(n)$ 的，因为前者往往伴有很大的常数，所以在当前规模下几乎必定跑不过后者。

**解法3: 主席树（可持久化线段树）**

感觉是这个问题的唯一解法。

**解法4: 每次用归并排序暴力找**

时间复杂度：$O(m n)$​

修改是$O(1)$​的

**解法5: 如果不是区间的话，或者这个区间可以用滑动窗口得以解决的话**

在树状数组上倍增，就可以求解rank(k)

具体过程就是模拟对k进行二进制拆解，一个倒叙的循环，每次找到最大的满足（tr[x]+tot）

```c++
int kth(int k)
{
	int l=0,tot=0,x,y;  // tot表示累计值，l表示累计左端点（每次的起点）
	for(int i=log(n);i>=0;--i)
	{
		x=l+(1<<i);  // x表示的是当前区间长度+累计的左端点，即当前的枚举的位置
		if(x>n)continue;
		y=tot+tr[x];  // y表示的是枚举到当前区间长度的tr[]+累计值
		if(y<k)l=x,tot=y;  // 若y小于k，则更新，否则就继续枚举更短的区间长度
	}
	return l+1;  // 返回的是第一个大于rank(k-1)的值的位置，这样有效避免了重复值
}
```

单次的更新和查询都是$O(\log n)$ 整体复杂度 $O(m\log n)$ ，但是缺点是除非可以滑动窗口或者莫队什么的，否则不容易维护区间的rank。

## 线性单调结构

--------

在很多题目的分析中，尤其是涉及到大小关系的题目里，观察那些东西还未确定答案/那些可能成为答案是十分重要的，换句话说，及时地剔除掉不可能成为答案的数据和已经成为答案的数据后，可能会发现候选集合有了单调性，这将帮助我们更好地找到问题的答案。

### 单调栈

引入问题1：给你一列数字，对每个数字求出左边第一个值大于它的数字的位置。要求做到$O(n)$ 

**问题1：**$有一列n个数字 a[1]...a[n]，对于所有的 1 \le L \le R \le n, 求\sum max(a[L],a[L+1],...,a[R])$

数据范围：$1\le n\le 10^6$​ 

思考过程：

由于对于仅仅枚举区间的时间复杂度就已经超过了上限，所以考虑贡献法。

考虑什么时候a[i]会对答案产生贡献，我们就需要找到a[i]左面和右面第一个比他大的值。在这个区间内，所有包含a[i]的区间的贡献都是a[i]。有了引入问题的预处理，我们可以很好的知道这个问题的最终时间复杂度就是O(n)

**问题2：**$有一列n个数字，求解一对(L,R)，使得(R-L+1)\times \min(a[L],a[L+1],...,a[R]) 最大$ 

数据范围：$1\le n \le 10^6$ 

思考过程：

和上面的题目类似，由于枚举区间的时间复杂度就已经超过了上限，所以考虑思考贡献。

枚举可能对答案产生贡献的位置a[i]，同理求出左面第一个大于它的和右面第一个大于它的位置，然后尝试更新答案即可

**问题3：**$有一个布尔矩阵（每个位置都是0或者1），求这个矩阵中最大的全是1的子矩阵$ 

数据范围：$n*m \le 10^6$

思考过程：

还是从数据范围入手，这个数据范围只能够枚举两维度，直接用枚举法求解的话，枚举所有的矩阵至少是 $O(n^2m^2)$ 的时间复杂度，很明显不可以。所以考虑贡献法。

这个题目直观上感觉只是把上一个题目从1维扩展到了2维。

先尝试枚举一维，处理第二维度。即，先枚举行号，从上到下面扫过来，然后在$O(m)$的时间复杂度内，我们就很容易得到一行值（设当前行为第i行），长度为m（列数）。其中 $a[i][j]$ 表示的是前i行种，从 $(i,j)$ 位置出发，向上有多少个连续的 1 的数量。然后我们就可以按照**问题2**的套路，$O(m)$ 的计算这一行对答案的贡献。最终整体的复杂度是 $O(n*m)$​ 的。

**[问题4：](https://codeforces.com/contest/1299/problem/C)**给你n个数字，你可以选择任意一段把这些数字改成他们的平均数。可以重复该操作任意次，要求使得最后的序列的字典序最小。

数据范围：$1\le n,a_i \le 10^6$​ 

思考过程：

提示字典序最小不难想到逐个位置确认。暴力这么做的复杂度是一个跑不满的 $O(n^2)$ ，因为如果找到一个区间的平均值就是这个起点情况下的最小平均值，那么这个区间的所有值就都确定了，最理想情况下可以到$O(n)$ ，考虑怎么优化。注意到最终的答案一定是单调递增的。我们可以模拟一个单调栈。如果出现了当前段的平均值小于上一段那我们就弹出上一段，和当前段合并。

### 单调队列

引入：通常用来解决**滑动窗口**问题。

滑动窗口问题的性质：满足所有可能产生答案的区间的左右端点单调。即，有$L_i\le L_{i+1} \;\& \; R_i \le R_{i+1}$ , 那么就能够在O(n)的时间复杂度完成。

**思想：**其实和单调栈差不多，区别只是在队的出入方式和栈道出入方式不同，其他没有任何不同。（甚至感觉单调队列的右端点在滑动的过程中为了保持单调性的操作就是一个单调栈）

**问题4：**$给一列n个数字a[1],a[2],...,a[n]，求最大的区间[L,R]使得该区间的数字之和S不小于0$ 

数据范围：$1 \le n \le 10^6 $ 

思考过程：

还是经典的不能枚举区间，直接思考哪些位置可能对答案产生贡献。

考虑前缀和，然后问题转化成了对于每一个数字找到在他前面的离他最远的小于他的数字的位置。

**解法1：**我们很容易维护一个单调栈，**维护一个数值单调递减的单调栈，然后每次在上面二分**就能在 $O(n\log n)$ 的时间复杂度内解决。（和权值线段树比有更小的常数）

**解法2：**考虑到对于每一个询问也是有单调性的，所以我们可以双指针。首先从最左边开始每次找一个比当前值小的值，建立一个单调递减的单调栈（指针1指向栈的末尾）。然后从右侧开始每次遍历一个比当前值大的值（指针2从最右侧开始遍历）。考虑对于每一个指针2，指针1如果能弹栈且保持弹栈后的栈顶元素小于指针2的值的话，谈栈一定是优秀的。时间复杂度 $O(n)$

### 大根堆/小根堆（BST 二叉搜索树）

Binary Search Tree

支持的操作：（若题目仅仅考察前4个操作，可以直接用set，没必要手写）

1. 插入
2. 删除
3. 找一个节点的前驱节点和后继节点（中序遍历上前面的最后一个数和后面的第一个数）
4. 找最大值和最小值
5. 求某个元素的排名
6. 求排名为k的那个元素
7. lower_bound，求比某个数（可以为非堆中元素）小的最大值
8. upper_bound，求比某个数（可以为非堆中元素）大的最小值
9. 如果希望用树简单实现set的删除操作的话，可以再开一个堆去表示标记元素被删除了，然后用的时候两个堆对着跳就可以了，唯一要注意的是删除过程中必须保证删除的数字是堆中存在的。

**问题1：**维护一个序列的动态中位数，支持插入和查询操作，若用set也支持删除操作

**问题2：**行有序的第k大（多路归并算法）

有一个 $n\times m$ 的表，每一行的数字都是按照从小到大的顺序排列的。你可以$O(1)$ 的时间查询任何一个位置的值。现在询问这个表中第k小的值，共有q次询问。

数据范围：$1\le n\times m\le 10^6, q\le 10^5$ 

思考过程：

**解法1：**首先不难想到一个暴力，就是二分这个值是多少，然后对于每一行进行二分查找，看这个值是不是第k个。得到一个 $O(qn\log m)$ 的算法。

**解法2：**构造一个大小为n的堆，把每一行的队头都放到堆里，每次弹出哪一行的就加上哪一行的后面的，考虑多路归并算法，离线所有的询问，我们可以在 $O(nm\log n)$ 的时间复杂度内解决所有问题，考虑到常熟不大，可以解决。

**问题3：**第k小点对和

$ 给定两个序列 a[1],a[2],...,a[n]\;和\;b[1],b[2],...,b[m],对于所有的点对(x,y)，求解a[x]+b[y]中的第k小的值是多少$ 

数据范围：$1\le n,m,k\le10^5$ 

思考过程：

首先，随手给两个序列都排好序，按照从小到大。虽然两个端点都满足单调性，但是排出双指针算法，因为双指针算法的精华在于即使否定掉不可能对答案产生贡献的点，但这道题目是求第k小的值，也就是说，所有的点对答案都应该有贡献，所以可以排出双指针。

考虑多路归并，假设我们找到了一个 $n*m$ 的矩阵，$v[i][j]$ 表示的是 $a[i]+b[j]$ 的值，然后考虑**上一个问题**就可以了。

### 基础字典树

​	也叫做**前缀树**，每个样本都从头节点开始根据前缀自负或者前缀数字建立出来一颗大树，这就是前缀树。注意字母一定是存在边上而不是存在点上。

​	每次都从根节点出发，便利当前节点是否有指向目标节点的边，要是有就复用节点，没有就新建节点。另外在每个点都存两个信息，一个是P（Passed）一个是E（Ended），这两个信息可以帮助我们很好地在前缀树上进行查询。

​	前缀树的优点：根据前缀信息选择树上的分支，可以节省大量的时间

​	前缀树的缺点：比较浪费空间，和总字符数有关也和字符的种类有关

```c++
// 实现方式2：利用链式前向星来实现
#include <iostream>
#include <cstdio>
#include <cstring>
#include <algorithm>
#include <cmath>

const int N=1000000;
int trie[N+2][26],tot=1;
bool end[N+2];

void insert(char *str) {  // 初始化，假设字符串都是由小写字母构成
    int len=strlen(str),p=1;  // 插入一个字符串
    for (int k=0;k<len;k++) {
        int ch=str[k]-'a';
        if (trie[p][ch]==0) trie[p][ch]=++tot;
        p=trie[p][ch];
    }
    end[p]=true;
}

bool search(char *str) {  // 检索字符串是否存在
    int len=strlen(str),p=1;
    for (int k=0;k<len;k++) {
        p=trie[p][str[k]-'a'];
        if (p==0) return false;  // 中途断了肯定不存在
    }
    return end[p];  // 看前面是否记录过
}

int main()
{
    int n,m;
    std::cin>>n>>m;
    for (int i=1;i<=n;i++) {  // 输入字符串并建立字典树
        char c[N+2];
        scanf("%s",c);
        insert(c);
    }
    for (int i=1;i<=m;i++) {  // 检索字符串是否存在
        char c[N+2];
        scanf("%s",c);
        std::cout<<search(c)<<std::endl;
    }
    return 0;
}
```

```c++
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <map>
#include <queue>
#include <vector>
const int N = 1e5;
int mapp[N + 2], s[N + 2], trie[N + 2][2], tot, end[N + 2];

void insert(int x, int point) {
    int p = 1;
    for (int i = 10; i >= 0; i--) {
        int ls = 0;
        if (x >= (1 << i)) {
            ls = 1;
            x -= (1 << i);
        }
        if (trie[p][ls] == 0) trie[p][ls] = ++tot;
        p = trie[p][ls];
    }
    end[p] = point;
}

int search(int x) {
    int p = 1, xx = x;
    for (int i = 10; i >= 0; i--) {
        int ls = 1;
        if (x >= (1 << i)) {
            ls = 0;
            x -= (1 << i);
        }
        if (trie[p][ls])
            p = trie[p][ls];
        else
            p = trie[p][(ls ^ 1)];
    }
    return s[end[p]] ^ xx;
}

int main() {
    int t;
    std::cin >> t;
    while (t--) {
        for (int i = 0; i <= tot; i++) {
            end[i] = 0;
            trie[i][0] = trie[i][1] = 0;
        }
        tot = 1;

        int n;
        std::cin >> n;
        for (int i = 1; i <= n; i++) {
            std::cin >> mapp[i];
            s[i] = s[i - 1] ^ mapp[i];
            insert(s[i], i);
        }
        int ans = -10000000;
        for (int i = 0; i <= n; i++) {
            ans = std::max(ans, search(s[i]));
        }
        std::cout << ans << std::endl;
    }
    return 0;
}
```



### 可持久化字典树

注意数组尺寸的计算

例题：[最大异或和](https://www.acwing.com/problem/content/258/)

时间复杂度

思路：首先利用前缀和进行处理，并且借鉴利用字典树找一个数列中的最大异或和数对的方法

题目需要额外满足两个限制，限制第一是 $p\le r-1$ ，这个可以利用可持久化trie（从时间维度上让不满足这个条件的数据不出现在当前检索的trie的版本中（即以root[r-1]为跟节点的trie中）），第二个限制是 $p\ge l-1$ ，这个限制则需要魔改一下end[]数组，end[x]表示可持久化trie的节点x是序列s[]中第几个二进制数字的结尾，若不是结尾节点，则end[x]=-1。现在这个数组变成了latest[]，latest[x]表示可持久化trie以x为根的子树中end的最大值。由于本题目中所有数字都按照24位二进制数来处理（长度是固定的且唯一的），所以理论上我们不需要end[]来切实发挥作用，所以可以用latest[]直接取代end数组。

```c++
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <queue>
#include <vector>

const int N = 6e5, M = N * 25;
int n, m, mapp[N + 2], s[N + 2], latest[M + 2], root[N + 2], trie[M + 2][2],
    tot;

// 这里为了方便更新latest，进行了递归插入。在普通trie中可以直接用循环去跳
// 当前插入的位置是s[i]的第k位,p表示在上一个跟节点中与q（当前跟节点）相同的层的点点序号
void insert(int i, int k, int p, int q) { // p=root[n-1],q=root[n]
    if (k < 0) {
        // 表示插入结束
        latest[q] = i;
        return;
    }
    int c = (s[i] >> k) & 1;
    // 查询s[i]第k位是0还是1
    // 通过观察可持久化trie的图与目的即可得到如下两条规律
    if (p) {
        trie[q][c ^ 1] = trie[p][c ^ 1];
        // 1.对于新根下与原树不相同的部分直接复制即可
    }
    trie[q][c] = ++tot;  // 2.对于新根下与原树相同的部分要建立新节点
    insert(i, k - 1, trie[p][c], trie[q][c]);
    // 对于新根下与原树相同的部分继续递归处理，不同部分复制结束后已经不用再去处理了
    latest[q] = std::max(latest[trie[q][0]], latest[trie[q][1]]);
}

int ask(int now, int val, int k, int limit) {
    if (k < 0) {
        return val ^ s[latest[now]];
    }
    int c = (val >> k) & 1;
    if (latest[trie[now][c ^ 1]] >= limit) {
        // 肯定满足latest[trie[now][c ^ 1]] != -1
        now = trie[now][c ^ 1];
    } else
        now = trie[now][c];
    return ask(now, val, k - 1, limit);
}

int main() {
    latest[0] = -1;
    // 在trie中，节点序号为0表示空，表示没有这条边，所以标记为-1
    root[0] = ++tot;
    insert(0, 24, 0, root[0]);  // s[0]也是合法前缀和,需要先插入

    std::cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        std::cin >> mapp[i];
        s[i] = s[i - 1] ^ mapp[i];
        root[i] = ++tot;
        insert(i, 24, root[i - 1], root[i]);
    }
    while (m--) {
        char c;
        std::cin >> c;
        if (c == 'A') {
            int a;
            std::cin >> a;
            mapp[++n] = a;
            s[n] = s[n - 1] ^ a;
            root[n] = ++tot;
            insert(n, 24, root[n - 1], root[n]);
        } else {
            int l, r, x;
            std::cin >> l >> r >> x;
            // 本体使用了前缀和进行计算，所以范围转变为[l-1,r-1];
            std::cout << ask(root[r - 1], x ^ s[n], 24, l - 1) << std::endl;
        }
    }
    return 0;
}
```

```c++
#include <iostream>
#include <cstdio>
#include <cmath>
#include <algorithm>
#include <vector>

const int N = 1e5;
typedef long long ll;
struct group {
	int l, r;
	ll add, mul, sum;
} setr[N * 4 + 2];
ll mapp[N + 2], mod;
int n, m;

void pushup(group &u, group &l, group &r) {
	u.sum = (l.sum + r.sum) % mod;
}
void pushup(int u) {
	if (setr[u].l == setr[u].r) return ;
	pushup(setr[u], setr[u << 1], setr[u << 1 | 1]);
}
void eva(group &u, ll add, ll mul) {
	// 先 * 后 + 先算优先级高的
	// evaluation
	u.sum = u.sum * mul % mod;
	u.sum = (u.sum + (u.r - u.l + 1) * add % mod) % mod;
	u.mul = u.mul * mul % mod;
	u.add = (u.add * mul % mod + add) % mod;
}

void pushdown(group &u, group &l, group &r) {
	// 注意：本层的一定是计算完成的，懒标记标记的是下一层的值的改变情况
	eva(l, u.add, u.mul), eva(r, u.add, u.mul);
	u.add = 0, u.mul = 1;
}
void pushdown(int u) {
	pushdown(setr[u], setr[u << 1], setr[u << 1 | 1]);
}

void build(int u, int l, int r) {
	if (l == r) {
		setr[u] = {l, l, 0, 1, mapp[l]};
		return ;
	}
	setr[u] = {l, r, 0, 1};  // 一定小心mul没有初始值的情况
	int mid = (l + r) >> 1;
	build(u << 1, l, mid), build(u << 1 | 1, mid + 1, r);
	pushup(u);
}

void modify(int u, int l, int r, ll add, ll mul) {
	if (setr[u].l >= l && setr[u].r <= r) {
		eva(setr[u], add, mul);
		return ;
	}
	pushdown(u);  // 请及时pushdown
	int mid = (setr[u].l + setr[u].r) >> 1;
	if (l <= mid) modify(u << 1, l, r, add, mul);
	if (r > mid) modify(u << 1 | 1, l, r, add, mul);
	pushup(u);
}

group query(int u, int l, int r) {
	if (setr[u].l >= l && setr[u].r <= r) return setr[u];
	pushdown(u);  // 请及时pushdown
	int mid = (setr[u].l + setr[u].r) >> 1;
	if (l > mid) return query(u << 1 | 1, l, r);
	else if (r <= mid) return query(u << 1, l, r);
	else {
		group res, left = query(u << 1, l, r), right = query(u << 1 | 1, l, r);
		pushup(res, left, right);
		return res;
	}
}

	std::ios::sync_with_stdio(0);
	std::cin.tie(0), std::cout.tie(0);
	std::cin >> n >> mod;
	for (int i = 1; i <= n; i++) {
		std::cin >> mapp[i];
		mapp[i] %= mod;
	}
	build(1, 1, n);
	std::cin >> m;
	for (int i = 1; i <= m; i++) {
		int op, t, g, c;
		std::cin >> op;
		if (op == 1) {
			std::cin >> t >> g >> c;
			modify(1, t, g, 0, c);
		}
```

### 势能分析（均摊！）

有些时候一些看似暴力的操作其实也是可行的。势能分析的朴素思想是我们可以给每个节点定义一个势能函数，对于势能为0的节点我们都不再需要操作。如果一个暴力操作会使得势能函数降低很快，那么这个暴力操作或许就是可行的。这个思想有点类似于均摊时间复杂度。

**如果一个暴力操作会让后续操作越来越简单，那不妨试试暴力。**

对于一般的套路，势能可能是最大值，最小值，区间和，极差。

**问题1：**有一个长度为n的序列，m次操作，每次指定一个区间 $[l,r]$ ，可能的操作为以下四种之一：1.区间加一个数c，2.区间除一个数d（向下取整）3.区间查询最小值，4.查询区间和【雅礼集训2017 市场】

数据范围：$n,m \le 10^5,\; -10^4\le a_i,c,d\le 10^4$ 

思考过程：

这四个操作中最难维护的是区间的下取整除法。但是观察发现，d最小是2（d==1的情况可以忽略），那么一个数字最多log次就一定会变成0，换句话说，如果只考虑除法一个区间最多被操作log次就一定会变成一样的。那么我们一个节点（线段树上一个节点就是表示一个区间）定义势能函数为一个区间的极差。当势能函数为0的时候这个节点就可以当作一个数来处理了。当势能函数不是0的时候我们暴力除法，暴力统计势能函数。

**这里m表示值域。**考虑每个数字对多被操作 $\log m$ 次，且操作每个数字需要操作从根节点到该数字的 $\log n$ 个节点，所以最终的复杂度是 $O(n\log m)$ （这里与操作次数无关，因为是均摊复杂度），单次修改最高的复杂度应该是 $O(2n)$ 

还需要考虑加法对势能函数的影响。加法操作只会影响被部分修改的区间（节点）。显然，最坏情况下一次加法操作最多破坏$\log n$ 个节点的势能函数，也就是说，一次加法最多会提供 $\log n \times m$ 的总势能，即会增加 $\log n \log m$​​ 次操作（因为对于长的整块增加，我们需不需要对整个更改的区间进行暴力操作，因为这些区间的势能（极差）并没有被增加，只需要对那些在线段树上被拆分成”零碎“的区间暴力，最多会操作log个单个节点，然后pushup就可以了）。

应为有复数参与运算，所以向下取整并不安全，在-1这个地方需要特判。

总时间复杂度 $O(n\log m+q\log n \log m)$​ 

**问题2：**维护一个长度为n的序列，m次操作。每次操作指定一个区间 [l,r] ，可能的操作为以下三种之一：1.给定一个常数t，对所有的 [l,r] 之内的 $a:=\min(a,t)$ ，2.查询区间最大值，3.查询区间和【HDU5306 Gorgeous Sequence】

数据范围：$n,m\le 10^6 $ 

思考过程：

这道题目按照上一个思考或许会有一点难。每次操作相当于把一个区间的“头”平整。但是这样无法保证多少次操作之后这个区间一定就相等了。

观察发现，这道题目没有什么加减乘除操作。唯一的操作每次都会让最大值减小，这就是在启发我们可以试试暴力去做了。



### 线段树分治

概述：什么时候你可以想到线段树分治，就是你在使用一个没有办法撤销的机构的时候，你可以选择保存一个数组log次，然后每次仅仅往里面插入就好了。

**问题1：**$有n个点，m条边，对于每条边有x,y,a,b四个参数，表示这条边是链接x，y两个节点，且出现时间为[a,b]$ 询问从1到k每个时间点是否为二分图。

```c++
		puts(tag ? "Yes" : "No");
```

### 可持久化线段树（主席树）

可持久化线段树与可持久化trie用来控制区间[l,r]的操作不相同，很大程度上是因为trie维护的东西不具有可加减性，所以效率要更低下，而线段树维护的内容在可加减的原因下便于维护。

**例题1：**[第K小数](https://www.acwing.com/problem/content/257/)

数据范围：$1\le n\le10^5,1\le m\le 10^4,|a[i]|\le 10^9$

思考过程：

整体的思路还是考虑在线段树上二分，这样来保证复杂度是单log，和普通在线段树上二分的唯一区别就是持久化可以支持区间查询。具体的就是r为根的版本前缀和-l为根的版本前缀和，然后根据这个值来决定向左递归还是向右递归。

由于是在值域上开线段树，也没有考虑离散化，所以采用动态开点。时间复杂度 $O((n+m)\log n)$ ,

```c++
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <queue>
#include <vector>

const int N = 2e6, M = 1e5;
struct node {
    // 这里存的是左右儿子的编号，不是区间的左右端点
    int lc, rc;
    int cnt;
} setr[N + 2];
int n, m, mapp[M + 2], tot, root[M + 2];
std::vector<int> dis;

// 这道题目不会用到
int build(int l, int r) {
    // 这里建立的线段树由于可持久化操作，所以并不满足二叉树的子父逻辑
    // 采用与trie相似的迭代方式
    int p = ++tot;
    if (l == r) {
        // 不用去更新lc和rc，默认为0即可，表示没有子节点
        setr[p].cnt = 1;
        return p;
    } else {
        int mid = (l + r) >> 1;
        setr[p] = (node){build(l, mid), build(mid + 1, r), setr[setr[p].lc].cnt + setr[setr[p].rc].cnt};
        return p;
    }
}

int ask(int p, int q, int l, int r, int k) {
    if (l == r) return l;
    int mid = (l + r) >> 1;
    int lcnt = setr[setr[p].lc].cnt - setr[setr[q].lc].cnt;
    // cnt表示的是当前节点所包含的数字个数，这里作差是同一层但是不同版本的作差，用来求出来题目要求的[l,r]内的数字个数
    if (k <= lcnt)
        return ask(setr[p].lc, setr[q].lc, l, mid, k);
    else
        return ask(setr[p].rc, setr[q].rc, mid + 1, r, k - lcnt);
}

// 这题由于是在值域上开可持久化线段树，所以插入的所有值全都是1，不需要最后一个参数
int insert(int now, int l, int r, int x) {
    int p = ++tot;
    setr[p] = setr[now];
    if (l == r) {
        setr[p].cnt++;
        return p;
    }
    int mid = (l + r) >> 1;
    if (x <= mid)
        setr[p].lc = insert(setr[now].lc, l, mid, x);
    else
        setr[p].rc = insert(setr[now].rc, mid + 1, r, x);
    setr[p].cnt = setr[setr[p].lc].cnt + setr[setr[p].rc].cnt;
    return p;
}

int main() {
    std::cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        std::cin >> mapp[i];
        dis.push_back(mapp[i]);
    }
    std::sort(dis.begin(), dis.end());
    dis.erase(unique(dis.begin(), dis.end()), dis.end());
    // root[0] = ++tot;
    // insert(0, 1, (int)dis.size(), 0);
    for (int i = 1; i <= n; i++) {
        mapp[i] = std::lower_bound(dis.begin(), dis.end(), mapp[i]) - dis.begin() + 1;
        root[i] = tot + 1;
        insert(root[i - 1], 1, (int)dis.size(), mapp[i]);
    }
    for (int i = 1; i <= m; i++) {
        int a, b, x;
        std::cin >> a >> b >> x;
        std::cout << dis[ask(root[b], root[a - 1], 1, (int)dis.size(), x) - 1] << std::endl;
    }
    return 0;
}
```

### 动态开点和线段树合并

题目链接：[雨天的尾巴](https://www.luogu.com.cn/problem/P4556)

时间复杂度：

对于在树上进行区间修改的操作直接用差分进行，然后用前缀和来进行结果查看。每一次前缀和都是对两颗线段树来进行合并。我们来思考这件事情，题目只是在结果进行一次查看，为什么会发现线段书合并更快呢？是因为操作数量比较少，加上动态开点，每个节点上的点的数量也比整个一排数组少。如果操作数量也很多的话，那可能真的会变慢。

```c++
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <vector>

const int N = 2000002, M = 2000002;
int ver[N * 2 + 2], head[N + 2], nxt[N * 2 + 2], f[N + 2][30], dep[N + 2];
int tot, root[N + 2], total, t, n, m, sz;
struct group {  // 用来把操作离线
    int x, y, z;
} op[M + 2];
struct node {
    int l_s, r_s;  // 左右儿子
    int dat, num;  // 最大值 物品类型
} setr[N * 4];

void add(int x, int y) {
    tot++;
    ver[tot] = y;
    nxt[tot] = head[x];
    head[x] = tot;
}

int build() {
    total++;
    setr[total] = {0, 0, 0, 0};
    return total;
}

void pushup(node &u, node &l, node &r) {
    if (l.dat >= r.dat) {
        u.dat = l.dat;
        u.num = l.num;
    } else {
        u.dat = r.dat;
        u.num = r.num;
    }
}
void pushup(int u) {
    // 用左右儿子向上计算
    pushup(setr[u], setr[setr[u].l_s], setr[setr[u].r_s]);
}

void modify(int u, int l, int r, int val, int delta) {
    if (l == r) {  // 若找到一个点，就更改
        setr[u].dat += delta;
        setr[u].num = val;  // 该点的最大值一定来自自己
        return;
    }
    int mid = (l + r) >> 1;
    if (val <= mid) {
        if (!setr[u].l_s) setr[u].l_s = build();  // 动态开点
        modify(setr[u].l_s, l, mid, val, delta);
    } else {
        if (!setr[u].r_s) setr[u].r_s = build();
        modify(setr[u].r_s, mid + 1, r, val, delta);
    }
    pushup(u);
}

void dfs(int x) {
    for (int i = 1; i <= t; i++) {
        f[x][i] = f[f[x][i - 1]][i - 1];
    }  // 倍增父亲预处理
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (dep[y]) continue;
        dep[y] = dep[x] + 1;
        f[y][0] = x;
        dfs(y);
    }
}

int lca(int x, int y) {
    if (dep[y] > dep[x]) std::swap(x, y);
    for (int i = t; i >= 0; i--) {
        if (dep[f[x][i]] >= dep[y]) x = f[x][i];
    }
    if (x == y) return x;
    for (int i = t; i >= 0; i--) {
        if (f[x][i] != f[y][i]) {
            x = f[x][i];
            y = f[y][i];
        }
    }
    return f[x][0];
}

int merge(int p, int q, int l, int r) {
    if (!p) return q;
    if (!q) return p;
    if (l == r) {
        setr[p].dat += setr[q].dat;
        return p;
    }
    int mid = (l + r) >> 1;
    setr[p].l_s = merge(setr[p].l_s, setr[q].l_s, l, mid);
    setr[p].r_s = merge(setr[p].r_s, setr[q].r_s, mid + 1, r);
    pushup(p);
    return p;
}

void deal(int x) {
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (dep[y] < dep[x]) continue;
        deal(y);
        merge(root[x], root[y], 1, sz);  // 把y树加到x树上去
    }
}

int main() {
    std::cin >> n >> m;
    for (int i = 1; i < n; i++) {
        int a, b;
        std::cin >> a >> b;
        add(a, b);
        add(b, a);
    }
    t = (int)(log(n) / log(2)) + 1;
    dep[1] = 1;
    dfs(1);

    std::vector<int> q;  // 用于离散化的数组
    for (int i = 1; i <= m; i++) {
```

### 轻重链剖分

核心思想就是把一棵树通过一种编码的方式变成一个链，这个链上有很好的性质，比如一个节点的子树的序号肯定是连在一起的等等，通过这些性质，我们使用线段树即可在树上进行区间操作。

特别注意的是pushdown操作和懒标记。懒标记其实是对儿子生效的，对于本层节点已经完成了计算。

本模版在1e5的数据下是400+ms，基本已经算是顶着时限在跑了

题目链接：[模版](https://www.luogu.com.cn/problem/P3384)

```c++
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>

typedef long long ll;
const int N = 1e5;
ll mod, ver[N * 2 + 2], head[N + 2], nxt[N * 2 + 2];
ll w[N + 2], dep[N + 2], mapp[N + 2];
int tot, n, m, root, sz[N + 2], son[N + 2], id[N + 2], top[N + 2], cnt, fa[N + 2];  // sz表示子树大小,son表示重儿子的编号
struct node {
    int l, r;
    ll add, sum;
} setr[N * 4 + 2];

void add(int x, int y) {
    tot++;
    ver[tot] = y;
    nxt[tot] = head[x];
    head[x] = tot;
}

void dfs1(int x) {
    sz[x]++;
    int mason = 0;
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (y == fa[x]) continue;
        dep[y] = dep[x] + 1;
        fa[y] = x;
        dfs1(y);
        if (sz[y] > mason) {
            mason = sz[y];
            son[x] = y;
        }
        sz[x] += sz[y];
    }
}

void dfs2(int x, int topf) {
    id[x] = ++cnt;  // 是这种编码顺序配合便利顺序保证了所有重链的序号都是连在一起的，也保证了所有的子树都是连在一起的
    mapp[cnt] = w[x];
    top[x] = topf;
    if (!son[x]) return;
    dfs2(son[x], topf);
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (y == fa[x] || y == son[x]) continue;
        dfs2(y, y);
    }
}

void pushup(node &u, node &ls, node &rs) {
    u.sum = (ls.sum + rs.sum) % mod;
}
void pushup(int u) {
    if (setr[u].l == setr[u].r) return;  // 叶子结点直接返回
    pushup(setr[u], setr[u << 1], setr[u << 1 | 1]);
}

void build(int u, int l, int r) {
    if (l == r) {
        setr[u] = {l, r, 0, mapp[l]};  // 这是线段书递归的边界条件
        return;
    }
    setr[u] = {l, r, 0, 0};
    int mid = (l + r) >> 1;
    build(u << 1, l, mid);
    build(u << 1 | 1, mid + 1, r);
    pushup(u);
}

void pushdown(node &u, node &ls, node &rs) {
    ls.sum = (ls.sum + (ls.r - ls.l + 1) * u.add % mod) % mod;
    rs.sum = (rs.sum + (rs.r - rs.l + 1) * u.add % mod) % mod;
    ls.add = (ls.add + u.add) % mod;
    rs.add = (rs.add + u.add) % mod;
    u.add = 0;
}
void pushdown(int u) {
    if (setr[u].l == setr[u].r) return;  // 要是叶子结点直接返回,因为本层一定已经计算完成了
    pushdown(setr[u], setr[u << 1], setr[u << 1 | 1]);
}

node query(int u, int l, int r) {
    if (setr[u].l >= l && setr[u].r <= r) return setr[u];
    pushdown(u);
    int mid = (setr[u].l + setr[u].r) >> 1;
    if (l > mid)
        return query(u << 1 | 1, l, r);  // 这里的是一种避免无效搜索的优化，注意边界条件的等于号放在哪里
    else if (r <= mid)
        return query(u << 1, l, r);
    else {
        node res = {0, 0, 0, 0}, left = query(u << 1, l, r), right = query(u << 1 | 1, l, r);
        pushup(res, left, right);  // pushup其实就是合并的过程
        return res;
    }
}

void modify(int u, int l, int r, ll v) {
    // std::cout << u << " " << setr[u].l << " " << setr[u].r << " " << l << " " << r << std::endl;
    if (setr[u].l >= l && setr[u].r <= r) {
        setr[u].sum = (setr[u].sum + (setr[u].r - setr[u].l + 1) * v % mod) % mod;
        setr[u].add += v;  // add表示的值对本层已经计算完成了
        setr[u].add %= mod;
        return;
    }
    pushdown(u);
    int mid = (setr[u].l + setr[u].r) >> 1;  // 这里判断修改的区间和询问哪里不太一样，注意区别
    if (l <= mid) modify(u << 1, l, r, v);
    if (r > mid) modify(u << 1 | 1, l, r, v);
    pushup(u);
}

void upd_range(int x, int y, ll z) {
    while (top[x] != top[y]) {
        if (dep[top[x]] < dep[top[y]]) std::swap(x, y);
        modify(1, id[top[x]], id[x], z);  // 注意id的大小
        x = fa[top[x]];
    }
    if (dep[x] < dep[y]) std::swap(x, y);
    modify(1, id[y], id[x], z);  // 注意是y在x的上面，所以id[y]一定小于id[x]
}

ll q_range(int x, int y) {
    ll res = 0;
    while (top[x] != top[y]) {
        if (dep[top[x]] < dep[top[y]]) std::swap(x, y);
        res = (res + query(1, id[top[x]], id[x]).sum) % mod;
        x = fa[top[x]];
    }
    if (dep[x] < dep[y]) std::swap(x, y);
    res = (res + query(1, id[y], id[x]).sum) % mod;
    return res;
}

void upd_son(int x, ll y) {
    modify(1, id[x], id[x] + sz[x] - 1, y);
}

ll q_son(int x) {
    return query(1, id[x], id[x] + sz[x] - 1).sum;
}

int main() {
    scanf("%d%d%d%lld", &n, &m, &root, &mod);
    for (int i = 1; i <= n; i++) {
        scanf("%lld", w + i);
        w[i] %= mod;
    }
    for (int i = 1; i < n; i++) {
        int a, b;
        scanf("%d%d", &a, &b);
        add(a, b);
        add(b, a);
    }
    dep[root] = 1;
    dfs1(root);
    dfs2(root, root);
    build(1, 1, cnt);  // cnt==n
    for (int i = 1; i <= m; i++) {
        int a;
        scanf("%d", &a);
        if (a == 1) {
            int x, y;
            ll z;
            scanf("%d%d%lld", &x, &y, &z);
            z %= mod;
            upd_range(x, y, z);
        } else if (a == 2) {
            int x, y;
            scanf("%d%d", &x, &y);
            printf("%lld\n", q_range(x, y));
        } else if (a == 3) {
            int x;
            ll y;
            scanf("%d%lld", &x, &y);
            y %= mod;
            upd_son(x, y);
        } else {
            int x;
            scanf("%d", &x);
            printf("%lld\n", q_son(x));
        }
    }
    return 0;
}
```

### 可持久化并查集

**问题1：**$给出一个n个点m条边的无向图，每条边都有边权w，共Q次询问，每次给出k条边 $ 问这些边能否存在于一颗最小生成树上。链接：[Envy](https://www.luogu.com.cn/problem/CF891C)

思考过程：

首先考虑一次询问，只要模拟一遍kruskal的过程就好了，对于当前长度的边，如果有相同长度但是被标记的边的话，优先选择，如果无法选择被标记的边就一定是gg了。

还是考虑贡献法。根据最小生成树的性质，我们从小到大扫一遍所有长度的边。然后对于每种长度类型，计算该类型的边对于所有相关询问的贡献。具体的，我们对于q组询问全都预处理挂到不同长度类型的边上，然后遍历到当前长度类型的时候，找到所有包含该长度类型边的询问，处理该询问中该长度类型的边的贡献，然后利用回滚并查集回到上一个长度类型结束的状态，然后再重复，知道当前长度类型的所有询问都处理完成，然后下一步。

启发：

从这道题目来看，并查集就是描述集合之间的关系，也就是说，对于一个并查集的一个状态表示其实就是这一时刻的fa数组和sz数组所表示的值。更加具体的，假如上一个阶段已经完成，这个图有一定的连通性，如果想知道这个图对当前阶段的贡献。比如说这个阶段有5次询问，那么只要记录下每次询问的时候的find值就可以了。后续完全可以在这个find值上直接拿出来继续进行合并，继续进行处理。也就是说对于当前阶段的所有点，只要他的find值被记录下来，对他们来说就实现了当前状态的记录。

对于MST来说，核心思想还是，这个算法在任何时间上停下来都是一个正确的算法。即当前的最优秀一定是结果的最优秀，一定对结果产生贡献。现在更深刻一点就是，每一个阶段还是独立的。

### 边带权并查集（描述集合内部关系）

这种模型完美解决了相对关系问题。有这种问题，题干给的信息全部都是相对的关系，没有绝对的关系，最后相对关系互相产生相对关系，这样每次改变都是一大片。对于这种问题我们就通常使用边带权并查集，这个算法的精妙之处在于它解决的也全都是相对关系，没有什么是固定死的，我只是说明了a,b,c是一个集合，并且相互有什么关系，但是我没有给出他们的绝对关系，也许现在还是极“好人”，下一步就会变成极“坏人”，固定的是“极”，不固定的是好人和坏人。

```c++
#include <cstdio>
#include <cmath>

    int a,b;

{

}

{
    if (l=="odd") return 1;
    else return 0;

        std::cin>>mapp[i].a>>mapp[i].b>>mapp[i].c;
        mapp[i].a--;
        deq.push_back(mapp[i].a);
        deq.push_back(mapp[i].b);
    }
    std::sort(deq.begin(),deq.end());
    deq.erase(unique(deq.begin(),deq.end()),deq.end());
    for (int i=1;i<=m;i++) {
        mapp[i].a=lower_bound(deq.begin(),deq.end(),mapp[i].a)-deq.begin()+1;
        mapp[i].b=lower_bound(deq.begin(),deq.end(),mapp[i].b)-deq.begin()+1;
        int a=find(mapp[i].a);
        int b=find(mapp[i].b);
        if (a==b) {
            if ((d[mapp[i].a]^d[mapp[i].b])!=deal(mapp[i].c)) {
                std::cout<<(i-1)<<std::endl;
                return 0;
            }
        }
        else {
            fa[a]=b;
            d[a]=d[mapp[i].a]^d[mapp[i].b]^deal(mapp[i].c);
        }
    }
    std::cout<<m<<std::endl;
```

```c++
    std::cin >> t;
    while (t--) {
        int n, m;
        std::cin >> n >> m;
        for (int i = 1; i <= n; i++) {
            fa[i] = i;
            d[i] = 0;
        }
        int tag = 0;
        for (int i = 1; i <= m; i++) {
            int a, b;
            ll c;
            std::cin >> a >> b >> c;
            if (tag) continue;
            int f_a = find(a);
            int f_b = find(b);
            // std::cout << d[a] << " " << d[b] << std::endl;
            if (f_a != f_b) {
                d[f_a] = c - d[a];
                fa[f_a] = b;
            } else {
                if (c != d[a] - d[b]) tag = 1;
            }
        }
        if (tag)
            std::cout << "NO" << std::endl;
        else
            std::cout << "YES" << std::endl;
    }
    return 0;
}
```

```c++
                    fa[lll]=kkk;

            }

                    fa[lll]=kk;
                    fa[l]=kkk;

            }
        }
```
