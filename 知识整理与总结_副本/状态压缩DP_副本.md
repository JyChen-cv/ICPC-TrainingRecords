### 状态压缩DP概述：利用状态压缩优化DP运算的方法

### 引入问题：[最短Hamilton路径](https://ac.nowcoder.com/acm/contest/996/D)

* **brute-force method**：枚举n个点的全排列再分别计算时间长度然后比较，时间复杂度为 $$O_{(n*n!)}$$ 
* **状态压缩DP**：时间复杂度 $$O_{(n^2*2^n)}$$ 
* **状态设计**： $$F[i][j]$$ ，*i* 表示当前那些点已经走了，*j* 表示当前正处在哪个节点时的Hamilton路径长度
* **状态转移**： $$F[i][j]=\min\limits_{j\in\{i中的1\},k\in\{j中的1\}} \{f[i^\land 1<<j][k]+weight[k][j] \}$$ 
* **初始状态**： $$F[1][0]=0$$ 

```c++
int f[1<<20][20];
int hamilton(int n,int weight[20][20]) {
    memset (f,0x3f,sizeof(f));
    f[1][0]=0;
    for (int i=1;i<(1<<n);i++) {
        for (int j=0;j<n;j++) if ((i>>j)&1) 
            for (int k=0;k<n;k++) if ((i^1<<j)>>k&1) 
                f[i][j]=std::min(f[i][j],f[i^1<<j][k]+weight[k][j]);
    }
    return f[(1<<n)-1][n-1];
}
```

### 例题1:[Mondriaan's Dream](http://poj.org/problem?id=2411)

* **思路**：逐行拆解目标矩阵，我们可以发现一点规律，当第一行摆着竖着放置的长方形块，我们下一行必须有对应的位置来放置一个竖着长方形的下半块

* **状态设计**： $$F[i][j]$$ 表示第 i 行形态为 j 时，前 i 行的分割方案的总数。 j 是用十进制记录的 M 位二进制数

* 问题难点（bushi）：我们只区分了竖着放置的上半块是1，其他是0。1对应位置下面肯定是0，但是无法保证是横的0，还是竖着的下半块的0。前者的情况需要我们去排除掉。

* **状态转移**：第 i-1 行形态 k，转换为第 i 行形态 j ，当且仅当（纯数学规律的探索，就像解析几何里面翻译条件一样）

  1. j 和 k 按位与后的结果 $$l=0$$ 
  2. j 和 k 按位或后的结果 p ，p 的二进制表示中，每一段连续的 0 都必须是偶数个

  $$F[i][j]=\sum\limits_{j\& k=0,j|k \in S}\{F[i-1][k] \},S表示所有符合条件的p的集合$$ 

```c++
#include <iostream>
#include <cstdio>
#include <cmath>
#include <algorithm>
#include <cstring>

const int N=11;
long long f[N+2][(1<<N)+2];
bool S[(1<<N)+2];
int n,m,t[(1<<N)+2];

int lowbit(int x) 
{
    return x&(-x);
}
bool check(int x)
{
    int point=0;
    while (x) {
        int l=t[lowbit(x)];
        if ((l-point)%2==1) return 0;
        else {
            x-=lowbit(x);
            point=l+1;
        }
    }
    if ((m-point)%2==1) return 0;
    return 1;
}

int main()
{
    for (int i=0;i<=N;i++) t[1<<i]=i;
    while (std::cin>>n>>m && n) {
        memset (S,0,sizeof(S));
        for (int i=0;i<=(1<<N);i++) {
            if (check(i)) S[i]=1;
        }

        f[0][0]=1;
        for (int i=1;i<=n;i++) {
            for (int j=0;j<(1<<m);j++) {
                f[i][j]=0;
                for (int k=0;k<(1<<m);k++) {
                    if ((j&k)==0 && S[j|k]) f[i][j]+=f[i-1][k];
                }
            }
        }
        std::cout<<f[n][0]<<std::endl;
    }

    return 0;
}
```
