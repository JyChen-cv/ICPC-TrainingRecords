## 拓扑序

> 一个合格拓扑排序 $v_1,v_2,...,v_n$ ，当且仅当你存在 i,j 使得 i<j ，但是不会存在一条从 $v_j到v_i的$ 边

[可达性统计](https://www.acwing.com/activity/content/problem/content/1577/)

```c++
#include <algorithm>
#include <bitset>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>

using namespace std;
const int N = 30000;

int ver[N + 2], nxt[N + 2], head[N + 2], tot;
int n, m, du[N + 2], q[N + 2];
std::bitset<N + 2> f[N + 2];

void add(int x, int y) {
    tot++;
    du[y]++;
    ver[tot] = y;
    nxt[tot] = head[x];
    head[x] = tot;
}

void topsort() {
    int hh = 1, tt = 0;
    for (int i = 1; i <= n; i++) {
        if (!du[i]) q[++tt] = i;
    }

    while (hh <= tt) {
        int x = q[hh++];
        for (int i = head[x]; i; i = nxt[i]) {
            int y = ver[i];
            if (--du[y] == 0) {
                q[++tt] = y;
            }
        }
    }
}

int main() {
    std::cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int a, b;
        scanf("%d%d", &a, &b);
        add(a, b);
    }
    topsort();
    for (int i = n; i >= 1; i--) {
        int x = q[i];
        f[x][x] = 1;
        for (int j = head[x]; j; j = nxt[j]) {
            int y = ver[j];
            f[x] |= f[y];  // 更新方式有点奇怪
        }
    }
    for (int i = 1; i <= n; i++) {
        printf("%zu\n", f[i].count());
    }
    return 0;
}
```

### 树上求并集求交集



例题1：

题目描述：

**例题2：**[捉迷藏](https://www.luogu.com.cn/problem/P2056) 

题目描述：有一颗n个顶点的有根树。m次操作，每次可以将1，某个节点染色为黑色或者白色；2，询问树上最远的两个黑色节点的距离；这两个操作实行。

数据范围：$n,m\le 10^5$

思考过程：首先，先根据题意排除一系列不带修改的树上操作。比如点分治，虚树什么的。根据定理。一棵树可以被转换成唯一的一串括号序列。然后我们就把一个树上的操作转换到了线段上的操作。

考虑任何一对黑色的点，他们的距离一定可以被表示成形如 $))))...)(...((($ 这样一串序列。这是因为子啊括号序列中，）表示回溯，（表示递归。一对黑色点在树上的距离是先向上再向下的一段序列。值得一提的是，这串序列并不是连续的，中间匹配的括号被忽略了。

那么现在问题转换成了在整个序列里，找一个最长的，端点颜色是黑色的形如上式的子序列，要求带修改。考虑线段树。

线段树维护每个区间内的上式的长度。pushup的操作就是把左区间的右括号和右区间的左括号能匹配的匹配。然后如何计算答案呢？类似于维护最大子段和，左右搞搞就维护出来了。。。

PS：有个算法叫做动态点分治。

### 求一颗子树内深度为固定值k的节点数量

原题干：找一个子树内和目标节点深度相同的其他节点的数量（编号），多组询问

原题目：[Blood Cousins](https://codeforces.com/problemset/problem/208/E) 

做法一：把这棵树dfs一边，所有深度相同的节点放到一个vector里面，然后给所有节点标号，记为dfs序列，然后利用lca的fa数组有目标节点向上跳，就可以找到该节点的k位父亲，然后在目标深度的vector上二分查找这个父亲的dfs区间即可

做法二：（启发式合并）这个问题的本质是求一颗子树内深度为固定值k的节点数量（答案就是这个数量-1），我们可以用启发式合并离线求出整个答案。我们需要对每棵子树都用（STL动态开点哈希）unordered_map来进行求解。，维护不同的深度（种类）以及每种深度出现的次数。

### 启发式合并（dsu on tree）(静态链分治)

适合解决树上离线问题

实现方式1: 重新定义合并函数，在合并的时候判断两者的size大小，从小向大合并（直接加一个swap就行，交换地址）

实现方式2: 把每个节点的儿子都拆分成轻儿子和重儿子，采用一遍轻儿子一遍重儿子再一遍轻儿子的方法进行合并。采用这种方式的主要原因是因为空间限制，我们没有办法为所有节点都一直记录一组答案，那我们就只能通过调整顺序来满足这一组答案始终是当前节点的答案。这就会有个问题，就是对于与当前节点关系不大的节点我们没法直接保留现在的答案去更新，我们需要清空然后去更新，我们当然希望清空的次数越少越好，我们就发明了这个算法，来减少清空次数。

有些性质例如（最大值查询）等适合线段树等性质的话可能可以尝试线段树合并来进行暴力求解

**启发式合并的本质是用代码复杂度的提升换来（优化空间和优化时间）是双重优化。我的意思是如果一道题目的数据范围只有5000，时间空间都不缺的话那就别优化了，直接暴力 $O(n^2)$​​ 转移就行**

例如这道题目就是明显可以暴力转移的

[Wonderful Tree!](https://codeforces.com/problemset/problem/1987/E)

[讲解dsu on tree](https://www.luogu.com/article/gz3u3qez) 

```c++
// Lomsat gelral
// https://codeforces.com/problemset/problem/600/E

#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <vector>
#define int long long
using namespace std;
const int N = 3e5 + 10;
struct Edge {
    int nex, to;
} edge[N << 1];
int head[N], TOT;
void add_edge(int u, int v)  // 链式前向星建图
{
    edge[++TOT].nex = head[u];
    edge[TOT].to = v;
    head[u] = TOT;
}
int sz[N];    // sz[u] 表示以 u 为根的子树大小
int hson[N];  // hson[u] 表示 u 的重儿子
int HH;       // HH 表示当前根节点的重儿子
int c[N];     // 表示每个节点的颜色
int cnt[N];   // cnt[i]表示当前子树中，颜色 i 出现了多少次
int ans[N];   // 每个点为根的答案
int n, res, ma;
// ma  表示出现次数最多的颜色出现的次数
// res 表示出现次数最多的颜色的颜色值总和 （两颜色出现次数相同则都要算）
void dfs(int u, int far) {
    sz[u] = 1;
    for (int i = head[u]; i; i = edge[i].nex)  // 链式前向星
    {
        int v = edge[i].to;
        if (v == far) continue;
        dfs(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[hson[u]]) hson[u] = v;  // 选择 u 的重儿子
    }
}
void calc(int u, int far, int val)  // 统计答案
{
    if (val == 1) {
        cnt[c[u]]++;
        if (cnt[c[u]] > ma)
            ma = cnt[c[u]], res = c[u];
        else if (cnt[c[u]] == ma)
            res += c[u];
    } else
        cnt[c[u]]--;
    for (int i = head[u]; i; i = edge[i].nex) {
        int v = edge[i].to;
        if (v == far || v == HH) continue;  // 如果 v 是当前根节点的重儿子，则跳过
        calc(v, u, val);
    }
}
void dsu(int u, int far, int op)  // op 等于0表示不保留信息，等于1表示保留信息
{
    for (int i = head[u]; i; i = edge[i].nex) {
        int v = edge[i].to;
        if (v == far || v == hson[u]) continue;  // 如果 v 是重儿子或者父亲节点就跳过
        dsu(v, u, 0);                            // 先遍历轻儿子 ，op = 0 :轻儿子的答案不做保留
    }
    if (hson[u]) dsu(hson[u], u, 1), HH = hson[u];
    // 轻儿子都遍历完了，如果存在重儿子，遍历重儿子（事实上除了叶子节点每个点都必然有重儿子）
    // op = 1 ， 保留重儿子的信息
    // 当前是以 u 为根节点的子树，所以根节点的重儿子 HH = hson[u]
    calc(u, far, 1);                             // 再次遍历轻儿子统计答案
    ans[u] = res;                                // 更新答案
    HH = 0;                                      // 遍历结束 ，即将返回父节点，所以取消标记 HH
    if (!op) {
        std::cout<<u<<" "<<far<<" "<<res<<" "<<ma<<std::endl;
        calc(u, far, -1); 
        ma = 0, res = 0;
        }  // 如果 op = -1，则 u 对于它的父亲来说是轻儿子，不需要将信息传递给它的父亲
}
signed main() {
    // freopen("/Users/chenjiayou/Desktop/2024暑假训练/DsuOnTree/okok.in", "r", stdin);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> c[i];
    for (int i = 2; i <= n; i++) {
        int u, v;
        cin >> u >> v;
        add_edge(u, v), add_edge(v, u);
    }
    dfs(1, 0);
    // for (int i = 1; i <= n; i++) {
    //     std::cout << i << ": " << hson[i] << std::endl;
    // }
    dsu(1, 0, 0);
    for (int i = 1; i <= n; i++) cout << ans[i] << " \n"[i == n];
    return 0;
}
```

~~~c++
// Blood Cousins
// https://codeforces.com/problemset/problem/208/E
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <vector>

const int N = 1e5;
int tot, head[N + 2], nxt[N * 2 + 2], ver[N * 2 + 2];
int sz[N + 2], son[N + 2], fa[N + 2][30], dep[N + 2];
int ans[N + 2], hh, rem[N + 2];  // 深度为i的节点的数量
std::vector<std::pair<int, int>> q[N + 2];

void add(int x, int y) {
    tot++;
    ver[tot] = y;
    nxt[tot] = head[x];
    head[x] = tot;
}

void dfs(int x) {
    sz[x] = 1;
    for (int i = 1; i <= 20; i++) fa[x][i] = fa[fa[x][i - 1]][i - 1];
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (y == fa[x][0]) continue;
        fa[y][0] = x;
        dep[y] = dep[x] + 1;
        dfs(y);
        sz[x] += sz[y];
        if (sz[y] > sz[son[x]]) son[x] = y;
    }
}

void calc(int x, int val) {
    if (val == 1) {
        rem[dep[x]]++;

    } else
        rem[dep[x]]--;
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (y == fa[x][0] || y == hh) continue;
        calc(y, val);
    }
}

void dsu(int x, int op) {
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (y == fa[x][0] || y == son[x]) continue;
        dsu(y, 0);
    }
    if (son[x]) {
        dsu(son[x], 1);
        hh = son[x];
    }
    calc(x, 1);
    hh = 0;
    if (q[x].size()) {
        for (auto i : q[x]) {
            ans[i.second] = rem[i.first] - 1;
        }
    }
    if (!op) {
        calc(x, -1);
    }
}

int main() {
    // freopen("/Users/chenjiayou/Desktop/2024暑假训练/DsuOnTree/okok.in", "r", stdin);
    int n, m;
    std::cin >> n;
    std::vector<int> root;
    for (int i = 1; i <= n; i++) {
        int a;
        std::cin >> a;
        if (a)
            add(a, i), add(i, a);
        else
            root.push_back(i);
    }
    for (auto i : root) {
        dep[i] = 1;
        dfs(i);
    }

    std::cin >> m;
    for (int i = 1; i <= m; i++) {
        int a, b;
        std::cin >> a >> b;
        int bb = b;
        for (int i = 20; i >= 0; i--) {
            if (bb >= (1 << i)) {
                bb -= (1 << i);
                a = fa[a][i];
            }
        }
        if (a == 0) {
            ans[i] = 0;
            continue;
        }
        q[a].push_back(std::make_pair(b + dep[a], i));
    }
    for (auto i : root) {
        dsu(i, 0);
    }
    for (int i = 1; i <= m; i++) {
        std::cout << ans[i] << " \n"[i == m];
    }
    return 0;
}
~~~

```c++
// 2024HDU暑期多校训练赛1的第3题

#include <iostream>
#include <cstdio>
#include <algorithm>
#include <cmath>
#include <vector>
#include <queue>
#include <map>
#include <unordered_map>
#include <cstring>
#include <set>

#define int unsigned long long
typedef long long ll;
typedef double db;
typedef std::pair<int, int> PII;
const int N = 5e5, M = 5e5, MAX = 1e6;
int head[N + 2], nxt[M * 2 + 2], ver[M * 2 + 2], tot;
int n, A[N + 2], sz[N + 2], hson[N + 2];
int cnt[MAX + 2], sm[MAX + 2], sm2[MAX + 2], ans[N + 2];
int Hson, nfa;

void add_edge(int x, int y) {
	tot++;
	ver[tot] = y;
	nxt[tot] = head[x];
	head[x] = tot;
}
int lowbit(int x) {
	return x & (-x);
}
void add(int p, int x, int *v) {
	while (p <= MAX) { // 开全局变量n
		v[p] += x;
		p += lowbit(p);
	}
}
int query(int p, int *v) {
	int res = 0;
	while (p) {
		res += v[p];
		p -= lowbit(p);
	}
	return res;
}
int sum(int l, int r, int *v) {
	if (l > r) std::swap(l, r);
	return query(r, v) - query(l - 1, v);
}

void dfs(int x, int fa) {
	sz[x] = 1;
	for (int i = head[x]; i; i = nxt[i]) {
		int y = ver[i];
		if (y == fa) continue;
		dfs(y, x);
		sz[x] += sz[y];
		if (sz[y] > sz[hson[x]]) hson[x] = y;  // 不为0就是说明有重节点，就是说明不是叶子节点
	}
}
void contribution(int val) {
	int res_c = query(val, cnt), res_s = query(val, sm);
	int res_ss = sum(val + 1, MAX, sm), res_s2 = sum(val + 1, MAX, sm2);
	int res = res_c * val * val - res_s * val;  // 前缀贡献
	res += res_s2 - res_ss * val;  // 后缀贡献
	// std::cout << nfa << " : " << res_c << " " << res_s << " " << res_ss << " " << res_s2 << " " << res << std::endl;
	ans[nfa] += res;
}
void calc(int x, int fa, int op) {
	if (op == 1) {
		contribution(A[x]);  // 其实这里无所谓先后顺序，因为自己和自己是0
		add(A[x], 1, cnt), add(A[x], A[x], sm), add(A[x], (int)A[x]*A[x], sm2);
	}
	else {
		add(A[x], -1, cnt), add(A[x], -A[x], sm), add(A[x], -(int)A[x]*A[x], sm2);
	}
	for (int i = head[x]; i; i = nxt[i]) {
		int y = ver[i];
		if (y == fa || y == Hson) continue;
		calc(y, x, op);
	}
}
void dsu(int x, int fa, int op) {
	for (int i = head[x]; i; i = nxt[i]) {
		int y = ver[i];
		if (y == fa || y == hson[x]) continue;
		dsu(y, x, 0);
	}
	if (hson[x]) {
		dsu(hson[x], x, 1), Hson = hson[x];  // 感觉放出去也没错
		// 先搜索然后再赋值，因为是全局变量，定义现在情况下的重儿子
		ans[x] += ans[hson[x]];  // 传递重儿子的贡献
	}
	nfa = x;  // 定义现在正在计算的是谁的贡献，当前处理的是哪个节点
	calc(x, fa, 1); // 再次便利亲儿子统计答案
	// 在这里计算答案

	// 计算完成，开始准备按照op回溯
	Hson = 0;
	if (!op) {  // 处理轻儿子
		calc(x, fa, 0); // 这里开0进行清理
		// 此处清理其他全局变量，重儿子是不用清理的，只有轻儿子需要被清理
	}
}
void solve() {
	std::cin >> n;
	for (int i = 1; i < n; i++) {
		int a, b;
		std::cin >> a >> b;
		add_edge(a, b), add_edge(b, a);  // 小心重名，和建立图的add函数撞了
	}
	for (int i = 1; i <= n; i++) {
		std::cin >> A[i];
	}
	dfs(1, 0);
	dsu(1, 0, 0);
	for (int i = 1; i <= n; i++) {
		// std::cout << i << ": " << ans[i] << std::endl;
		ans[i] ^= ans[i - 1];
	}
	std::cout << ans[n] * 2 << std::endl;
}

signed main() {
	std::ios::sync_with_stdio(0);
	std::cin.tie(0), std::cout.tie(0);
	int times = 1;
	// std::cin >> times;
	while (times--) {
		solve();
	}
	return 0;
}
```

### 求最近公共祖先（LCA）

**就强调一点，根节点的深度务必和0节点深度不同**

#### 倍增法

题目：[门的锁链](https://www.acwing.com/problem/content/description/354/)

```c++
#include <iostream>
#include <cstdio>
#include <cstring>
#include <cmath>
#include <algorithm>

const int N=100000;
int ver[N*2+2],nxt[N*2+2],head[N],cnt[N+2],fa[N+2][30];
int tot,t,dep[N+2],n,m,ans1,ans2;

void add(int x,int y) {
    tot++;
    ver[tot]=y;
    nxt[tot]=head[x];
    head[x]=tot;
}

void dfs(int x,int f) {
    for (int i=1;i<=t;i++) {
        fa[x][i]=fa[fa[x][i-1]][i-1];
    }
    for (int i=head[x];i;i=nxt[i]) {
        int y=ver[i];
        if (y==f) continue;
        
        fa[y][0]=x;
        dep[y]=dep[x]+1;
        dfs(y,x);
    }
}

int lca(int x,int y) {
    // 先跳到同一层，再一起向上跳
    if (dep[y]>dep[x]) std::swap(y,x);
    for (int i=t;i>=0;i--) {
        if (dep[fa[x][i]]>=dep[y]) x=fa[x][i];
    }
    if (x==y) return x;
    for (int i=t;i>=0;i--) {
        if (fa[x][i]!=fa[y][i]) {
            x=fa[x][i];
            y=fa[y][i];
        }
    }
    return fa[x][0];
}

void deal(int x,int f) {
    for (int i=head[x];i;i=nxt[i]) {
        int y=ver[i];
        if (y==f) continue;
        deal(y,x);
        if (cnt[y]==0) ans1++;
        else if (cnt[y]==1) ans2++;
        cnt[x]+=cnt[y];
    }
}

int main()
{
    std::cin>>n>>m;
    t=(int)(log(n)/log(2))+1;
    for (int i=1;i<n;i++) {
        int a,b;
        std::cin>>a>>b;
        add(a,b);
        add(b,a);
    }
    dep[1]=1;
    dfs(1,0);
    for (int i=1;i<=m;i++) {
        int a,b;
        std::cin>>a>>b;
        int c=lca(a,b);
        cnt[a]++;
        cnt[b]++;
        cnt[c]-=2;
    }
    deal(1,0);

    std::cout<<(ans1*m+ans2)<<std::endl;
    
    return 0;
}
```

```c++
const int N = 5e5;

std::vector<int> query[N + 2], query_id[N + 2];

void add(int x, int y) {
    tot++;
    ver[tot] = y;
    nxt[tot] = head[x];
    head[x] = tot;
}

void add_query(int x, int y, int id) {
    query[x].push_back(y), query[y].push_back(x);
    query_id[x].push_back(id), query_id[y].push_back(id);
}

int find(int x) {
    if (fa[x] == x)
        return x;
    else
        return fa[x] = find(fa[x]);
}

void tarjan(int x) {
    v[x] = 1;
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (v[y]) continue;
        tarjan(y);
        fa[y] = x;
    }
    for (int i = 0; i < (int)query[x].size(); i++) {
        int y = query[x][i], id = query_id[x][i];
        if (v[y] == 2) {
            ans[id] = find(y);
        }
    }
    v[x] = 2;
}

int main() {
    int n, m, s;
    std::cin >> n >> m >> s;
    for (int i = 1; i <= n; i++) fa[i] = i;
    for (int i = 1; i < n; i++) {
        int a, b;
        scanf("%d%d", &a, &b);
        add(a, b);
        add(b, a);
    }
    for (int i = 1; i <= m; i++) {
        int a, b;
        scanf("%d%d", &a, &b);
        if (a == b)  // 这个特判一定要有,不然会无解
            ans[i] = a;
        else
            add_query(a, b, i);
    }
    tarjan(s);
    for (int i = 1; i <= m; i++) {
```

`````c++
    tot++;
    edge[tot] = z;
    ver[tot] = y;
    nxt[tot] = head[x];
    head[x] = tot;
}

void find(int x, int fa) {  // 原树顺序
    sz[x] = 1, mx[x] = 0;
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (y == fa || v[y]) continue;
        find(y, x);
        sz[x] += sz[y];
        mx[x] = std::max(mx[x], sz[y]);
    }
    mx[x] = std::max(mx[x], S - sz[x]);
    if (mx[x] < mx[root]) root = x;  // 这里感觉没必要，按理说找到一个就可以返回了，可能是和第一次便利有关吧
}

void getdis(int x, int fa) {  // 点分治树顺序遍历
    rem.push_back(d[x]);  // 记录下本次根节点的当前子节点搜索的所有深度
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        int z = edge[i];
        if (y == fa || v[y]) continue;
        d[y] = d[x] + z;
        getdis(y, x);
    }
}

void calc(int x) {
    // 这里其实不是向下便利，就只是当前节点的子节点
    std::vector<int> res;  // 记录下当前跟节点下的所有深度信息
    t[0] = 1;res.push_back(0);
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        int z = edge[i];
        if (v[y]) continue;
        rem.clear();
        d[y] = z;  // 初始化深度
        getdis(y, x);
        for (int j = 0; j < (int)rem.size(); j++) {
            for (int k = 1; k <= m; k++) {
                if (q[k] >= rem[j] && t[q[k] - rem[j]]) ans[k] = 1;
            }
        }
        for (auto i : rem)
            if (i <= 1e7) t[i] = 1, res.push_back(i);
    }
    for (auto i : res) t[i] = 0;  // 其实就是 memset 0，但是这样时间复杂度会爆炸，所以才这样操作。
}

void solve(int x) {
    // std::cout << x << std::endl;
    v[x] = 1;  // 保证了solve遍历不会出现循环
    calc(x);
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (v[y]) continue;
        find(y, x);  // 第一次其实就是求sz
        S = sz[y], root = 0, mx[0] = 1e9;
        find(y, x);
        solve(root);
    }
}
`````

## 最小生成树（MST）

> 关于同一张图上的最小生成树，有一些性质：
>
> - 对于任意权值的边，所有最小生成树方案包括的边中，这个权值大小的边的数量是一定的（交换法易证）
> - 对于任意合法的最小生成树加边方案，加完小于某权值的所有边后。此时图（森林）的连通性是一样的。换句话说，对于相同权值的边，我们选择的条数是一定的（性质1），而且具体选择其中哪几条边（只要是合法生成树）不会改变”当前权值的所有边处理完之后的图“的连通性。

**例题1：**[最小生成树的唯一性判断](http://poj.org/problem?id=1679) 

题目描述：给定一个图，求最小生成树是否为一

数据范围：$n\le 10^6$ 

思考过程：对于每一个阶段的判断哪些边目前是合法的，然后执行合并操作，在这一过程中如果有一开始合法的边变得不合法了。那就是不为一了。时间复杂度就是kruskal的时间复杂度。

### 次小生成树

先求一颗最小生成树，这一过程中其实可以顺带判断一下最小生成树是否为一，不为一的话直接输出最小生成树的答案就好了。否则直接遍历一遍所有的非树边，然后对于每一对顶点，lca一下原来树上的最大边权的边，然后替换就好了。

### 严格次小生成树

最小生成树的边权之和为 sum，严格次小生成树就是指边权之和大于 sum 的生成树中最小的一个

在最小生成树的基础上暴力维护一个次大值就可以了。。。

比非严格次小生成树要求更高，更为复杂，需要同时维护一条路径上的最小值和次小值（注意，不是排名前二的边的长度，因为可能前两名长度相同，则都不能用），这里因为不需要带修，所以没必要上树链剖分

题目链接：[次小生成树](https://www.acwing.com/problem/content/description/358/)

时间复杂度：$O(m\log m)$

```c++
#include <iostream>
#include <cstdio>
#include <cstring>
#include <algorithm>
#include <cmath>

const int N=3*1e5,INF=0x3f3f3f3f;
struct group {
    int x,y;
    long long z;
    bool operator < (const group &t)const {
        return z<t.z;
    }
} mapp[N+2];
int n,m,dep[N+2],f[N+2][30],tag[N+2],head[N+2],ver[N+2],nxt[N+2],t,v[N+2];
long long d1[N+2][30],d2[N+2][30],edge[N+2],tot,ans;

void add(int x,int y,long long z)
{
    tot++;
    edge[tot]=z;
    ver[tot]=y;
    nxt[tot]=head[x];
    head[x]=tot;
}

int find(int x)
{
    if (tag[x]==x) return x;
    else return tag[x]=find(tag[x]);
}

long long deal(long long x,long long y,long long z)
{
    if (x==y) return x-z;
    else return x-y;
}

void doo(long long &x,long long &y,long long a1,long long a2,long long b1,long long b2)
{
    x=std::max(a1,b1);
    if (a1==b1) y=std::max(a2,b2);
    else {
        if (a1>b1) y=std::max(b1,a2);
        else y=std::max(a1,b2);
    }
}

void dfs(int x,int fa,long long l)
{
    f[x][0]=fa;
    d1[x][0]=l;
    d2[x][0]=-INF;
    for (int i=1;i<=t;i++) {
        f[x][i]=f[f[x][i-1]][i-1];
        doo(d1[x][i],d2[x][i],d1[x][i-1],d2[x][i-1],d1[f[x][i-1]][i-1],d2[f[x][i-1]][i-1]);
    }
    for (int i=head[x];i;i=nxt[i]) {
        int y=ver[i];
        long long z=edge[i];
        if (y==fa) continue;
        dep[y]=dep[x]+1;
        dfs(y,x,z);
    }
}

long long lca(int x,int y,long long z)
{
    if (dep[x]<dep[y]) std::swap(x,y);
    long long max1=-INF,max2=-INF;
    for (int i=t;i>=0;i--) {
        if (dep[f[x][i]]>=dep[y]) {
            doo(max1,max2,max1,max2,d1[x][i],d2[x][i]);
            x=f[x][i];
        }
    }
    for (int i=t;i>=0;i--) {
        if (f[x][i]!=f[y][i]) {
            doo(max1,max2,max1,max2,d1[x][i],d2[x][i]);
            doo(max1,max2,max1,max2,d1[y][i],d2[y][i]);
            x=f[x][i];
            y=f[y][i];
        }
    }
    doo(max1,max2,max1,max2,d1[x][0],-INF);
    doo(max1,max2,max1,max2,d1[y][0],-INF);
    return deal(z,max1,max2);
}

int main()
{
    std::cin>>n>>m;
    t=log(n)/log(2)+1;
    for (int i=1;i<=m;i++) {
        int a,b;
        long long c;
        std::cin>>a>>b>>c;
        if (a==b) {
            i--;
            m--;
            continue;
        }
        mapp[i]=(group){a,b,c};
    }

    std::sort(mapp+1,mapp+m+1);
    for (int i=1;i<=n;i++) tag[i]=i;
    for (int i=1;i<=m;i++) {
        int a=find(mapp[i].x),b=find(mapp[i].y);
        if (a!=b){
            tag[a]=b;
            add(mapp[i].x,mapp[i].y,mapp[i].z);
            add(mapp[i].y,mapp[i].x,mapp[i].z);
            v[i]=1;
            ans+=mapp[i].z;
        }
    }
    dep[1]=1;
    dfs(1,0,-INF);

    long long res=INF;
    for (int i=1;i<=m;i++) {
        if (!v[i]) {
            res=std::min(res,lca(mapp[i].x,mapp[i].y,mapp[i].z));
        }
    }
    std::cout<<(ans+res)<<std::endl;

    return 0;
}
```

### 单调队列优化Dijkstra

优点：速度快且稳定，能处理分层图最段路等问题

缺点：不能处理负边

思路是从一个源点出发，一点点扩大子图的范围，在这个过程中从前到后逐步确定。

堆里存放的是被更新变小的点，同时按照距离源点点距离从小到大排序

对于已经弹出的点，将永远不会再被更新考虑

```c++
std::priority_queue<std::pair<int,int> > q;

void dijkstra(int p)
{
    memset (d,0x3f,sizeof(d));
    memset (v,0,sizeof(v));

    d[p]=0;
    q.push(std::make_pair(0,p));
    while (q.size()) {
        int x=q.top().second;
        q.pop();
        if (v[x]) continue;
        v[x]=1;
        for (int i=head[x];i;i=nxt[i]) {
            int y=ver[i];
            int z=edge[i];
            if (d[y]>d[x]+z) {
                d[y]=d[x]+z;
                q.push(std::make_pair(-d[y],y));
            }
        }
    }
}
```

#### SPFA判定负环

标准情况下判断效率为O(n*m)

例题：[虫洞](https://www.acwing.com/problem/content/906/)

spfa判负环有两种方式，判断一个点的入队次数以及判断最短路的路径数，考虑到最坏情况下前者会显著退化到O(n*m)所以采用第二个方法。前者也有一种比较trick（取巧）的方法，当所有点的总入队次数到达一定的范围后便判定大概率出现了负环

也可以同时用两种方法判定（见进阶指南P392）

```c++
#include <iostream>
#include <cstdio>
#include <cmath>
#include <algorithm>
#include <cstring>
#include <queue>

const int N=25000;
int n,m,w;
int head[N+2],nxt[N*2+2],ver[N*2+2],edge[N*2+2];
int tot,d[N+2],cnt[N+2],v[N+2];
std::queue<int> q;

void add(int x,int y,int z)
{
    tot++;
    edge[tot]=z;
    ver[tot]=y;
    nxt[tot]=head[x];
    head[x]=tot;
}

bool SPFA() 
{
    memset(d,0,sizeof(d)); // 注意这里是0
    memset(v,0,sizeof(v));
    memset(cnt,0,sizeof(cnt));
    
    for (int i=0;i<=n;i++) {
        q.push(i);
        v[i]=1;
    }
    while (q.size()) {
        int x=q.front();
        q.pop();
        v[x]=0;
        for (int i=head[x];i;i=nxt[i]) {
            int y=ver[i];
            int z=edge[i];
            if (d[y]>d[x]+z) {
                d[y]=d[x]+z;
                cnt[y]=cnt[x]+1; // 计算经过y的最短路的路径数
                if (cnt[y]>=n) return 1; // 最短路中最多也就n个点n-1条边，如果超过了，便判定
                if (!v[y]) q.push(y),v[y]=1;
            }
        }
    }
    return 0;
}

int main()
{
    int t;
    std::cin>>t;
    while (t--) {
        memset(edge,0,sizeof(edge));
        memset(nxt,0,sizeof(nxt));
        memset(head,0,sizeof(head));
        memset(ver,0,sizeof(ver));
        tot=0;
        std::cin>>n>>m>>w;
        for (int i=1;i<=m;i++) {
            int a,b,c;
            std::cin>>a>>b>>c;
            add(a,b,c);
            add(b,a,c);
        }
        for (int i=1;i<=w;i++) {
            int a,b,c;
            std::cin>>a>>b>>c;
            add(a,b,-c);
        }
        if (SPFA()) std::cout<<"YES"<<std::endl;
        else std::cout<<"NO"<<std::endl;
    }

    return 0;
}
```

### 差分约束系统

#### 情况1:对于所有的边权没有任何特殊限制

这种情况下SPFA算法比较好，最坏情况下会退化到O(nm)，通常情况下时间复杂度为O(km)

```c++
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <queue>

const int N = 1e5;
int tot, ver[N + 2], head[N + 2], nxt[N + 2], edge[N + 2];
int v[N + 2], d[N + 2], cnt[N + 2];
int n, m;

void add(int x, int y, int z) {
    tot++;
    ver[tot] = y;
    edge[tot] = z;
    nxt[tot] = head[x];
    head[x] = tot;
}

int spfa() {
    std::queue<int> q;
    v[0] = 1;
    q.push(0);
    memset(d, 0x3f, sizeof(d));
    d[0] = 0;
    while (q.size()) {
        int x = q.front();
        v[x] = 0;
        q.pop();
        for (int i = head[x]; i; i = nxt[i]) {
            int y = ver[i];
            int z = edge[i];
            if (d[y] > d[x] + z) {
                d[y] = d[x] + z;
                cnt[y] = cnt[x] + 1;
                if (cnt[y] >= n + 1) return 0;  // 这里一定要注意，有虚根0后，总个数是n+1个点
                if (!v[y]) {
                    q.push(y);
                    v[y] = 1;
                }
            }
        }
    }
    return 1;
}

int main() {
    std::cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int a, b, c;
        std::cin >> a >> b >> c;
        add(b, a, c);
        add(0, i, 0);  // 构建一个以0为根结点的虚根
    }
    int tag = spfa();
    if (tag) {
        for (int i = 1; i <= n; i++) {
            std::cout << d[i] << " ";
        }
        std::cout << std::endl;
    } else {
        std::cout << "NO" << std::endl;
    }
    return 0;
}
```

### 匈牙利算法

最大匹配问题，增广路径，最小点覆盖，最大独立集

**性质**：最大匹配=不存在增广路径

`````c++
#include <algorithm>
#include <cmath>
#include <cstdio>
#include <cstring>
#include <iostream>
#include <queue>
#include <vector>

const int N = 5e4;
int head[1002], nxt[N + 2], ver[N + 2], tot;
int visit[1002], match[1002];

void add(int x, int y) {
    tot++;
    ver[tot] = y;
    nxt[tot] = head[x];
    head[x] = tot;
}

bool dfs(int x) {
    for (int i = head[x]; i; i = nxt[i]) {
        int y = ver[i];
        if (visit[y]) continue;
        visit[y] = 1;
        if (!match[y] || dfs(match[y])) {
            match[y] = x;
            return 1;
        }
    }
    return 0;
}

int main() {
    int n, m, k;
    std::cin >> n >> m >> k;
    for (int i = 1; i <= k; i++) {
        int a, b;
        std::cin >> a >> b;
        b += n;
        add(a, b);
    }

    int ans = 0;
    for (int i = 1; i <= n; i++) {
        memset(visit, 0, sizeof visit);
        if (dfs(i)) ans++;
    }
    std::cout << ans << std::endl;
    return 0;
}
`````

### 链优化建图

例题：ABC368E

思考过程：

首先这个题目是给定了一个表达式，简单转化一下变成了 $X_j \ge X_i+(T_i-S_j)$ 仔细观察这个式子发现可以用差分约束来进行求解。由于是大于等于号所以等价于在图上跑最长路。再进一步思考，题目保证了 $T_i\le S_j$ 也就是说，这个项永远是一个负数。那么就正好可以用DIjkstra算法了。但是我们再进一步思考，题目给出了这个条件说明这个图一定是一个DAG，那么我们直接按照拓扑序，对这个图进行简单的dp转移就好了。

考虑如何建图。很明显，最坏情况下，图的边最多有 $m^2$ 条边。考虑使用链优化建图。对于每个点都建立一条时间轴，这样我们就不用便利那些边符合题目规定的弱序关系了。
